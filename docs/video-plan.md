# 動画の構成（1〜3分）

目標は約2分。シミュレータの映像は等速で使い、待ち時間だけ早送りする（早送りした区間は画面に「2倍速」と出す）。

| 時間 | 場面 | 映像 | 字幕 |
|---|---|---|---|
| 0:00–0:10 | 題名 | 机の全景（front カメラ） | 言葉で頼めるお片付けロボットアーム |
| 0:10–0:25 | 仕組み | 図1枚（指示＋真上画像 → Claude → 座標 → アーム） | 画像と指示から「どれを・どこへ」を決める |
| 0:25–0:50 | 基本 | 「赤い箱を青い皿に置いて」の実行 | 指示文をそのまま表示 |
| 0:50–1:15 | 複数・言い換え | 「全部片付けて。赤いのは青い皿、ほかは黄色い皿に」 | 同上 |
| 1:15–1:35 | 位置関係 | 「一番左にある物を青い皿へ」（真上画像に Claude が指した点を重ねる） | 配置を見て決める |
| 1:35–1:50 | 断る | 「青い箱を黄色い皿へ」→ Claude の返答文を表示・アームは動かない | 無い物は運ばない |
| 1:50–2:05 | 結果 | 成功率の表 | 28通り × 5配置で 135/140 |
| 2:05–2:15 | 限界 | 「ボールを」で円柱を運ぶ場面 | 真上からは円柱が球に見える |

## 撮影の手順

- `scripts/record_scenes.py --planner claude` で5場面（基本・複数・位置関係・断る・ボール）を `outputs/scenes/claude/<場面>/` へ書き出す。1場面に真上画像 `overhead.png`・計画を重ねた `plan.png`・指示と返答文の `plan.json`・正面の動画 `video.mp4`
- 場面を足すときは同スクリプトの `SCENES` に（フォルダ名・指示の名前・配置）を足す。1つだけなら `scripts/run_instruction.py "<指示>" --planner claude --seed <配置> --video --name <フォルダ名>`
- 注記の見た目だけ直すときは `--redraw`（API を呼ばない）
- 字幕・つなぎは `scripts/make_video.py` で行う（編集ソフトは使わない）。`outputs/video.mp4`＝1280×720・約2分10秒・音声なし。並びは OP（`outputs/jingle/` にあれば）→題名→仕組み→基本→複数→位置関係→断る→結果→ACT との比較→ROS 2 版（ノードのつながりと実行ログ・素材は `ros2/record_run.sh`）→限界（ボール）→終わり→ED。各場面は頭3秒に plan.png、本編は左に正面映像・右に指示と Claude の返答。`--preview` で代表コマだけ確認できる。公開後に `--repo-url` を付けて書き直す
- 画面に個人情報（ユーザー名・パス・通知）を映さない。シミュレータの書き出し映像だけで組む
